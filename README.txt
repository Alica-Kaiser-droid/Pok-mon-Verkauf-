Pokémon → eBay Scanner V1

1. Diese Version ist ein iPhone-tauglicher Web-App-Prototyp.
2. Sie nutzt Tesseract.js im Browser für OCR und TCGdex für den Kartenabgleich.
3. Sie kann Fotos vom iPhone aufnehmen/auswählen und eine CSV-Arbeitsdatei erzeugen.
4. Die CSV ist absichtlich noch NICHT als endgültiges eBay-Seller-Hub-Template ausgegeben.
   eBay verlangt für Seller-Hub-Feeds ein konkretes Template/Schema. Dieses wird im nächsten
   Schritt an das von dir verwendete eBay-DE-Template angepasst.
5. Für die Installation als iPhone-Web-App muss index.html über HTTPS gehostet werden.
